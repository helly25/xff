# SquashFS test fixture

`mini.sqfs` is a deterministic 356-byte SquashFS 4.0 image generated with the independent
MIT-licensed [`KarpelesLab/squashfs`](https://github.com/KarpelesLab/squashfs) writer at v1.2.0. It
is committed rather than generated by libsqsh so the reader test cannot pass merely because one
implementation agrees with itself.

Its SHA-256 digest is
`1f0483aecd45d559fdfba63d89c3ce72dcea80a532880a16db7fecf1b4a1b784`. The tests pin its exact
members, byte contents, types, permissions, and link target. The image uses gzip-compressed metadata
and a fragment for its short file tails, so those two format paths are exercised by independent
bytes; the separate overlay link test verifies that gzip/LZMA/XZ/LZ4/Zstandard readers are all
registered while GPL-licensed LZO is absent:

| Member             | Type      | Mode   | Content / target           |
| :----------------- | :-------- | :----- | :------------------------- |
| `dir`              | directory | `0755` |                            |
| `dir/sub`          | directory | `0755` |                            |
| `dir/sub/data.bin` | file      | `0444` | `00 01 02 03 ff`           |
| `hello-link`       | symlink   | `0755` | target `hello.txt`         |
| `hello.txt`        | file      | `0640` | `hello from squashfs` + LF |

The AppImage cases prepend executable-like bytes in the test itself. That keeps one underlying image
while proving both retained-byte and path-backed use of libsqsh's archive-offset support.
